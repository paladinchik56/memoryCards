# Cards 📇

[English](README.md) · **Русский**

Приложение для карточек с интервальным повторением на Django. Создавайте карточки, повторяйте их
по расписанию, которое подстраивается под то, насколько хорошо вы знаете каждую, собирайте их в темы,
делитесь темами и учитесь офлайн на телефоне (мобильное приложение в разработке).

> **Статус: в разработке.** Функции ниже работают и покрыты тестами, но дизайн пока черновой.
> План — сделать новый дизайн и выпустить первую версию.

## Возможности

- **Интервальное повторение** — каждая карточка движется по фиксированной лестнице интервалов
  (от 90 секунд до 2 месяцев): верный ответ поднимает её на ступень, неверный — опускает на одну.
- **Переворот карточки** — нажмите на карточку, чтобы увидеть ответ (3D-переворот).
  Клавиши: → — верно, ← — неверно, пробел — перевернуть.
- **Темы (коллекции)** — группируйте карточки в темы с тремя уровнями доступа: приватная,
  по ссылке или публичная (видна в общей библиотеке).
- **Общая библиотека** — смотрите публичные темы других пользователей и копируйте себе карточки
  или темы целиком; скопированные карточки начинают с нуля.
- **Прогон темы** — пройти тему целиком кругами: каждый следующий круг — только ошибки прошлого.
  Не влияет на расписание повторений, прогресс сохраняется.
- **Вход по нику или email** — ник виден как автор опубликованных тем.
- **Тёмная тема** — переключатель вверху, запоминается.
- **Тестовый режим** — сжимает интервалы до секунд, чтобы проверить весь цикл без ожидания.

## Технологии

- **Сервер:** Django 6.1, Django REST Framework, SQLite (на боевом сервере планируется PostgreSQL),
  HTML-страницы с обычным CSS/JS.
- **Телефон (в разработке, `mobile/`):** Expo + React Native, TypeScript, локальная база SQLite,
  синхронизация с сервером при появлении сети.

Описание продукта, логики и дизайна — в папке [`description/`](description/):
- `idea-design-*.odt` — исходное описание страниц;
- `glossary.md` — словарь терминов;
- `algorithm-and-sync.md` — алгоритм повторения, хранение и синхронизация;
- `architecture.md` — структура и технологии;
- `open-decisions.md` — открытые вопросы и принятые решения;
- `design/` — эскизы экранов.

## Запуск

```bash
git clone https://github.com/paladinchik56/memoryCards.git
cd memoryCards
python -m venv .venv
source .venv/bin/activate        # в Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/` и зарегистрируйтесь. Коды подтверждения по умолчанию не отправляются
на почту, а печатаются в терминале, где запущен сервер.

На боевом сервере задайте переменную окружения `DJANGO_SECRET_KEY` (в репозитории только
небезопасный ключ для локальной разработки).

Тесты:

```bash
python manage.py test
```
