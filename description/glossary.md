# Словарь терминов

Два раздела: **логика** (понятия, по которым работает приложение) и **интерфейс** (что видно на экране:
где и при каких условиях). Термины выделены жирным так же, как в `idea-design-*.odt`.

---

## Логика

**Карточка** — вопрос и ответ. Принадлежит автору. Может лежать в теме, а может быть **без темы**.

**Вопрос / ответ** — две стороны карточки. На экране учёбы сначала виден вопрос, по нажатию —
ответ (переворот).

**Тема** — набор карточек: название, описание, теги, настройки приватности, список карточек.
Свои темы можно редактировать, добавленные (чужие) — нет.

**Колода** — список карточек внутри темы. Используется в кнопках «Редактировать колоду»
и «Удалить из колоды». По смыслу это та же тема, слово относится к её содержимому.

**Блитц** (раньше «бассейн») — все карточки, которые пользователь сейчас учит по алгоритму.
У каждой карточки в блитце свой уровень и время следующего повторения. В блитц можно положить:
- карточки из **своих тем** и **без темы**;
- карточки из **добавленных тем**;
- карточки из **чужих публичных тем**, даже не добавляя саму тему.
Карточка не уходит из блитца сама: даже выученная периодически возвращается. Убрать её из блитца
можно только удалением во время блитц-учёбы.

**Блитц-учёба** — учёба по карточкам блитца, время повторения которых наступило. Ответ двигает
карточку по уровням алгоритма. Можно отфильтровать по темам.

**Алгоритм повторения** — лестница из 6 уровней с интервалами 90 секунд, 30 минут, 12 часов,
2 дня, 2 недели, 2 месяца. Верный ответ — уровень вверх, неверный — на один вниз.
Подробно: `algorithm-and-sync.md`.

**Уровень (ступень)** — положение карточки на лестнице алгоритма, от 0 до 5.

**Выученная карточка** — карточка на максимальном уровне (5). Остаётся в блитце и возвращается
раз в 2 месяца.

**Прогресс** — уровень карточки и время следующего повторения. Отдельно есть прогресс
**прохода** в просто учёбе, он с прогрессом блитца не связан.

**Сбросить прогресс** — вернуть карточку в блитце на уровень 0 и поставить повтор на «сейчас».

**Просто учёба** — пройти одну тему целиком, без расписания. Не меняет прогресс блитца.

**Проход (круг)** — один раз через все карточки, оставшиеся в просто учёбе. Первый проход — все
карточки темы. Каждый следующий — только те, на которые в прошлом ответил неверно.

**Цикл** — все проходы по теме, пока не останется ошибок. «Начать цикл заново» — снова с первого
прохода. Состояние цикла сохраняется после каждого ответа.

**Добавленная тема** — чужая тема, которую пользователь «добавил себе». Только для чтения, всегда
в актуальном виде от автора. По ней можно делать просто учёбу, из неё можно копировать карточки
в свои темы и класть карточки в блитц.

**Без темы** — служебная тема в «Моих темах»: все свои карточки, не лежащие ни в одной теме.

**Настройки приватности** — кто видит тему: **приватная** (только автор), **по ссылке**
(кто получил ссылку), **публичная** (все, видна в «Смотреть библиотеку»).

**Публичный доступ** — тема с приватностью «публичная».

**Теги** — метки темы. По ним, названию и описанию работает поиск в библиотеке.

**Автор темы** — пользователь, создавший тему. Его публичные темы можно посмотреть списком.

**Синхронизация** — обмен изменениями между телефоном и сервером, когда есть сеть.
Учёба работает без сети, всё учтётся при следующей синхронизации.

## Интерфейс

### Вкладки (всегда внизу после входа)
| Элемент | Где и когда видно |
|---|---|
| **Учёба** | первая вкладка, открывается после входа |
| **Библиотека** | вторая вкладка |
| **Профиль** | третья вкладка |

### Вкладка «Учёба»
| Элемент | Где и когда видно |
|---|---|
| **Число к повторению** | главная вкладки «Учёба»: сколько карточек блитца ждут повторения сейчас |
| **Начать блитц** (блитц-учёба) | главная вкладки «Учёба». Если повторять нечего — «0 карточек, добавьте карточки в блитц» |
| **Просто учёба** | главная вкладки «Учёба» |
| **Добавить карточку** | главная вкладки «Учёба»; также внутри блитц-учёбы |
| **Посмотреть карточки** | главная вкладки «Учёба» |

### Экран «Блитц-учёба»
| Элемент | Где и когда видно |
|---|---|
| **Карточка** (вопрос → ответ) | по центру; нажатие переворачивает |
| **Верно / неверно** | после переворота: свайп вправо — верно, влево — неверно (или кнопки) |
| **Фильтр по темам** | вверху экрана; выбор одной или нескольких тем (свои и добавленные) |
| **Добавить карточку** | на экране блитц-учёбы; после добавления учёба сразу продолжается |
| **Удалить** | на экране блитц-учёбы; убирает текущую карточку **из блитца** (сама карточка остаётся) |
| **0 карточек, добавьте карточки в блитц** | вместо карточки, когда повторять нечего |

### Экран «Просто учёба»
| Элемент | Где и когда видно |
|---|---|
| **Выбор темы** | список «Мои темы» и «Добавленные темы» |
| **Продолжить с последнего места** / **Начать цикл заново** | при открытии темы, если прошлый цикл не закончен |
| **Проход N, осталось M** | вверху во время прохода |
| **Итог прохода** | после последней карточки прохода: сколько верно, кнопка «Следующий проход» или «Тема пройдена» |

### Экран «Добавить карточку»
| Элемент | Где и когда видно |
|---|---|
| **Вопрос**, **Ответ** | поля ввода |
| **Тема** | выбор из своих тем (или без темы); после добавления остаётся выбранной |
| **Добавить** | кнопка; после неё форма очищается и остаётся открытой |

### Экран «Посмотреть карточки»
| Элемент | Где и когда видно |
|---|---|
| **Таблица карточек блитца** | одна строка — одна карточка; колонки: тема, вопрос, (уточняется), через сколько повторение |

### Вкладка «Библиотека»
| Элемент | Где и когда видно |
|---|---|
| **Мои темы** | главная вкладки «Библиотека»: темы, созданные пользователем, плюс «Без темы» |
| **Добавленные темы** | главная вкладки «Библиотека»: чужие темы, добавленные себе |
| **Смотреть библиотеку** | главная вкладки «Библиотека»: все публичные темы, нужна сеть |

### Экран темы («Внутри темы»)
| Элемент | Где и когда видно |
|---|---|
| **Список карточек** | строка = карточка; колонки: вопрос, ответ |
| **Редактировать колоду** | только в своих темах; включает выделение карточек |
| **Удалить из колоды** | после выделения, только в своих темах; убирает карточки из темы |
| **Переместить** | после выделения, только в своих темах; в другую свою тему |
| **Скопировать** («откопировать») | после выделения; в свою тему. Доступно и в чужих темах |
| **Добавить в блитц** | после выделения; в своих, добавленных и чужих публичных темах |
| **Нажатие на карточку** | открывает карточку: в своей теме — изменить вопрос/ответ, **удалить карточку**, добавить в блитц; в чужой — добавить в блитц, скопировать в свою тему |
| **Добавить тему себе** | только в чужих темах, которых ещё нет в «Добавленных» |

### Диалог «Карточки уже в блитце»
| Элемент | Где и когда видно |
|---|---|
| **Пропустить** / **Сбросить прогресс** | при добавлении в блитц карточек, которые там уже есть; по каждой карточке |
| **Применить для всех карточек** | галочка в том же диалоге |

### Экран «Смотреть библиотеку»
| Элемент | Где и когда видно |
|---|---|
| **Поиск** | вверху; ищет по названию, описанию и тегам тем |
| **Список публичных тем** | под поиском |
| **Автор темы** | на экране чужой темы; нажатие открывает все его публичные темы |

### Вкладка «Профиль»
| Элемент | Где и когда видно |
|---|---|
| **Имя профиля** | вверху вкладки, рядом — время последней синхронизации и кнопка **Обновить** (синхронизировать сейчас) |
| **Статистика** | под именем: сколько карточек **в блитце**, сколько **выучено**, сколько **дней подряд** вы учились |
| **Как работает повторение** | раздел «Учёба»; открывает описание алгоритма повторения |
| **Напоминание о блитце** | раздел «Учёба»; время ежедневного напоминания или «выкл» |
| **Язык** | раздел «Приложение»; язык интерфейса (русский, английский) |
| **Оформление** | раздел «Приложение»; светлое, тёмное или как в системе |
| **Ник и пароль** | раздел «Аккаунт» |
| **Экспорт карточек** | раздел «Аккаунт»; выгрузка всех карточек в файл (CSV) |
| **Выйти** | раздел «Аккаунт» |
