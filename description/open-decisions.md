# Решения и открытые вопросы

## Принято

| # | Решение |
|---|---|
| 1 | Карточка и блитц — разные вещи. В блитц кладут карточки из своих тем, из добавленных тем и из чужих публичных тем (по одной или выделением, с вопросом «пропустить / сбросить прогресс» и «применить для всех»). Тему при этом добавлять не обязательно. |
| 2 | «Добавить тему себе» = тема появляется в «Добавленных темах» только для чтения (подписка, не копия). |
| 3 | Копия карточки в другую свою тему — независимая карточка, как копия файла. |
| 4 | Выученная карточка — на максимальном уровне алгоритма. Остаётся в блитце. |
| 5 | «Удалить» во время блитц-учёбы убирает карточку **из блитца**. «Удалить» при просмотре темы убирает её **из темы**. |
| 6 | Когда повторять нечего: «0 карточек, добавьте карточки в блитц». Термин «бассейн» заменён на «блитц». |
| 7 | Регистрация отложена. Для тестов — аккаунт администратора `admin`, вход на сайте и в приложении. |
| 8 | README на двух языках: `README.md` (англ.) и `README.ru.md`. |
| 9 | Дизайн главной — вариант **D** («число в центре»). |
| 10 | Описание и всё, что читаете вы, — на русском; код и комментарии — на английском; интерфейс переводимый (ru + en сейчас). |
| 11 | Принцип «одна функция — одно место». Лишние входы на сайте (Study в библиотеке, второй вход в блитц) будут убраны. |
| 12 | «Посмотреть карточки»: колонки **тема, вопрос, ответ, через сколько повторение**. |
| 13 | «Добавить карточку» с главной вкладки «Учёба» — карточка сразу попадает в блитц. |
| 14 | Профиль: имя, статистика (в блитце, выучено, дней подряд), синхронизация, «Как работает повторение» (описание алгоритма), напоминание о блитце, язык, оформление, ник и пароль, экспорт карточек, выход. Эскиз: `design/profile.png`. |
| 15 | Прогресс чужих карточек — вариант **A′**: при добавлении чужой карточки в блитц у пользователя создаётся её копия, связанная с оригиналом. Правки автора в копию не попадают. |
| 16 | Алгоритм: лестница 90 с → 30 мин → 12 ч → 2 дня → 1 неделя → 2 недели → 1 месяц (максимум). Для перехода нужно 3 верных ответа на ступенях 90 с / 30 мин / 12 ч и 2 — на 2 дня / 1 неделя / 2 недели. Верные ответы считаются всего, ошибка ничего не обнуляет и ступень не понижает. |
| 17 | После ошибки карточка возвращается в той же сессии через 5–6 других; ответ на вернувшуюся карточку **засчитывается**. |
| 18 | Порядок в блитце — вариант **C**: случайно, но сильно просроченные (относительно интервала ступени) раньше. Одна карточка не идёт два раза подряд. |
| 19 | Лимита новых карточек в день нет. |
